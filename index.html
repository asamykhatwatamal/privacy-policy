About the Application

The application is designed to support the use of the Picture Exchange Communication System (PECS) for individuals with disabilities.

The application is connected to the Khatwatamal Masar system and its backend services. The application communicates with our server primarily to authenticate users and provide access to the application's authorized features.

Information Used for Login

The application uses the information required for user authentication, such as the user's login credentials, to allow authorized users to sign in to the application.

Login information entered by the user is transmitted to our server through the application's secure connection for the purpose of authentication and access control.

The application does not use login information for advertising, marketing, behavioral profiling, or user analytics.

How We Use Information

Information transmitted to our server is used only for purposes necessary to operate the application, including:

  • Authenticating authorized users.
  • Managing user access to the application.
  • Providing the application's PECS-related functionality.
  • Maintaining the security and proper operation of the application.

We do not use user information for advertising, targeted advertising, behavioral profiling, or analytics.

Data Sharing

We do not sell, rent, or share users' personal information with third parties for advertising, marketing, or analytics purposes.

Information transmitted through the application may be processed and stored on servers operated by or on behalf of Khatwatamal solely to provide authentication, access control, and the services of the application.

Third-Party Services

The application does not intentionally use third-party advertising, marketing, or analytics services to collect information about users.

Data Security

We take reasonable technical and organizational measures to protect information transmitted through the application against unauthorized access, disclosure, alteration, or destruction.

Communication between the application and our server is protected using appropriate security measures, including encrypted communication where applicable.

Data Retention

Authentication and account information is retained on our systems only as necessary to provide authorized access to the application and the associated services, or as required for legitimate legal or security purposes.

Account Management

User accounts associated with the application are managed through the Khatwatamal Masar system and its backend services.

The mobile application does not use user account information for purposes unrelated to authentication, access control, or the application's core functionality.
